Shell integration
- zsh and bash get shell integration automatically, with no setup: sink
  marks where each prompt and command line begins (OSC 133) and reports
  the working directory (OSC 7)
- Prompt jumping with Cmd+Up/Down, and new tabs and splits opening in the
  current directory, now work without configuring the shell
- Your startup files load exactly as before, from the same places and in
  the same order. Works with prompt themes that rebuild the prompt every
  time, and with macOS's own bash 3.2
- Turn it off with shell_integration = false in sink.toml

Mouse editing
- Clicking to place the cursor works in multi-line and wrapped commands,
  and keeps working after a command is edited back down to one line. Clicks
  used to stop responding after any of those
- Clicks land on the right character past wide characters (CJK, emoji),
  after clearing the screen or resizing, and at zsh's continuation prompts
- Commands typed ahead of the prompt, while the last one still runs, can be
  clicked into like any other
- Clicking on a zsh autosuggestion no longer accepts it
- Deleting a selection across a line break removes the line break too
- Follows application cursor key mode, as oh-my-zsh sets it

Interface
- Text reflows live while a window is resized or a split divider is
  dragged, instead of when the mouse is released
- Full screen uses the whole screen, as Terminal.app does, instead of
  leaving a strip at the top for the hidden title bar
- Windows redraw at the right size on displays of a different pixel
  density: on a 1x external display, only part of the window used to show

Demos
- sinksing and sinkdemo type their lyrics out with the cursor gliding
  along, instead of showing them a line at a time
- Commands that merely mention sinkdemo or sinksing, like grep sinkdemo
  notes.txt, now run instead of swallowing Enter
- The demo's video fills the window on external displays and in full screen

Security
- The stand-in commands for sinkdemo and sinksing moved from /tmp, where
  another account could have planted programs that ran in every sink shell,
  to a private folder under ~/.config/sink
- Pasted text can no longer break out of bracketed paste and run commands,
  including text a program put on the clipboard with OSC 52
- kitty images sent as PNG are decoded only as PNG, keeping SVG and older
  image decoders out of reach of untrusted output
- A small sixel image can no longer freeze the window: 1.5 KB took over a
  second to decode, and now takes a millisecond
- Escape sequences with huge parameter lists or values no longer exhaust
  memory or move the cursor the wrong way
- Parser, grid and image decoders fuzzed with millions of hostile inputs
  under memory and undefined behavior sanitizers

Terminal emulation
- Erase below and above the cursor (ED 0 and 1), which shells use to clear
  completion lists and what a redraw left behind. Both were ignored
- Erasing to the end of a line ends its soft wrap, as in xterm

Bug fixes
- Resizing a window no longer erases lines of output above the prompt, or
  leaves stale copies of the command line behind
- Oversized sixel images keep the part that fits instead of disappearing
